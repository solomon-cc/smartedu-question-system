# 首页、游戏目录与评估入口调整

## 设计依据

先从 ui-ux-pro-max 官方仓库更新本机既有 skill，再进行页面修改。同步的是 main 的 `50d8a7de0900119855614541f15a1a616691eb33`；查询到的稳定发布为 v2.15.0。沿用项目已有 Vuetify 主题、字体和组件，采用克制的边框、统一间距与清晰的信息层级。

## 本次范围

- 老师首页：评估／学业发展两列，生活技能／游戏／干预三列，档案／素材两列；减少卡片高度，统一标题、图标和说明。平板两列，手机单列。
- 游戏目录：完整展示 3:2 场景图片，移除覆盖场景的装饰物和重复操作；每张卡片保留标题、说明、任务数量及一个入口。学生选择任务，老师试玩或准备教学。
- PEAK 评估：删除说明卡片中的“开始一次评估”，保留顶部唯一新建入口；缩小教师说明区域，让评估记录更早出现。学生仍无创建入口。
- 共用页面标题：清除浏览器默认标题和段落边距，保留既有字号与主题。

没有修改 API、数据模型、评分方式或角色权限。

## 验证

使用 Codex 内置浏览器的本地页面完成实际检查：

- 老师首页：1440×900、1024×768、768×1024、375×812，未出现横向溢出。
- 老师游戏目录：桌面与手机完整图片、单一操作入口；选择任务后可启动“老师预览 · 不保存记录”。本地正式场景记录仍为 1 条，没有因试玩新增。
- 学生生活练习：768×1024，两列完整图片，无教师目标说明／素材管理／试玩入口；任务选择对话框保留“开始练习”。
- 评估中心：老师桌面／手机和管理员 iPad 均可通过唯一新建入口打开并取消表单。手机按钮高度 44px。学生“我的评估”没有新建入口。
- 管理员评估区域深色主题采用主题色值；验收后恢复浅色主题与默认浏览器尺寸。
- 前端 23 个测试文件、88 项测试通过，包含新增的老师／管理员唯一创建入口回归测试。生产类型检查与构建通过，git diff --check 通过。已有 ExcelJS 大包提示仍为非阻塞构建提示。

# 游戏背景比例修复

原因：LifeGamePlayer 的电脑端背景使用 `100% 100%`，把原图独立拉伸到场景宽高；原来的手机规则使用 cover，因此问题主要出现在电脑和平板。

修复：共用背景改为 `center/cover`，所有场景按原图比例缩放并裁切超出的边缘。保持既有交互区、API、评分和记录逻辑不变。

已参考更新后的 ui-ux-pro-max 图片缩放与响应式规范，在 Codex 内置浏览器实际打开超市、点餐老师预览：1440×900、1440×720、1024×768、768×1024、375×812；计算样式均为 cover，无横向溢出。检查点餐／超市截图，并确认苹果可放入购物篮。正式场景记录仍为 1 条，试玩没有新增记录。验收结束恢复默认浏览器尺寸。

LifeGamePlayer、Scenarios 相关 9 项测试通过；生产类型检查和构建通过；git diff --check 通过。

仅发布前端，76 个文件 HTTPS SHA-256 校验通过；后端、权限及业务记录数量保持不变。备份：`/data/backups/testogo-20261009-214547`。本轮视觉检查使用本地真实 API 账户，线上校验为发布文件一致性校验。

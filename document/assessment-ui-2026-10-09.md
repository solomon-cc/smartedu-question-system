# 评估入口与 PEAK 展示优化

## 调整

- 学生入口为“我的评估”，老师与管理员为“评估中心”，方法名称在记录内明确标注 PEAK，避免通用入口绑定某一种工具。
- VB-MAPP 保留独立历史记录，入口收进“其他评估与历史档案”。没有修改历史数据、API、权限或评分规则。
- 评估记录采用响应式卡片，区分 D 直接训练 / G 泛化，支持进行中与已完成筛选。
- 详情先展示进度、正确 / 未通过或待巩固 / 未评及四组记录。学生看到任务组和任务编号，老师保留正式项目代码与施测提示。
- 查看记录不再自动进入全屏。老师或管理员点击“继续施测”后进入已有图片互动界面；新建记录后直接开始。
- 施测说明折叠，原始材料、评分说明、完成锁定与断点继续保持原有逻辑。

## 验证

- 前端角色测试覆盖学生只读与提示隔离、教师和管理员明确进入施测、错误时不误显示空记录。
- 完整前端测试和生产构建通过，保留原有 ExcelJS 大包提示。
- 已启动本地 Vite 与隔离 SQLite 后端。浏览器工具内置浏览器不可用，Chrome 创建标签超时，因此本次没有完成浏览器视觉与移动端实测；响应式检查仍需实际浏览器复核。

## 整套流程回归补充

验证方式：Vue 组件点击模拟 + 独立 SQLite 的真实 HTTP 接口。浏览器通道读取标签仍超时，以下不等同于真实浏览器视觉测试。

- 新增点击场景先复现 4 个失败断言，再修复：末尾回到暂跳项目、多页任务暂停、D/G 全部记录后的汇总入口。
- D 与 G 各 64 项逐项点击评分、保存、下一项，共 128 项；保存后明确提示“全部项目已记录”，返回汇总核对。
- 暂跳保持未评；自动继续优先找下一未评项目并回到前面漏评项，避免反复进入已评项。

- 路由离开保护：未保存评分时，返回保存取消离开并保留输入，放弃修改允许离开。
- 父页面接收评分后更新 64/64，退出施测、确认完成、返回列表均同步状态，完成后展示只读。
- 新建后如果列表或评分读取失败，不再意外打开此前评估的施测界面。
- 本地真实接口完成 D/G 新建、提前完成拒绝、128 次评分保存、重新读取、学生禁止评分、确认完成后禁止修改、管理员查看。

# 场景拖拽与公开登录入口

## 本次修正

用户截图中的步骤条、说明卡、清单和固定底部按钮共同挤压场景。游戏现在使用可视区域高度 `100dvh` 的两行容器：紧凑顶部工具栏 + 剩余空间的场景。物品、购物篮、收银台、钱包全部位于同一场景；没有独立步骤条、固定底部“下一步”或场景外的大清单。清单与提示缩为场景内的小物件。

- 商品通过 Pointer Events 拖入购物篮，可从篮中拖回货架；拖拽物品跟手显示，正确落点高亮。
- 购物篮拖到收银台才核对清单；清单不符保留原操作并提示。总价和找零在点开的收银机内计算，继续保留真实后台验证、错答重试与提示记录。
- 钱币从钱包拖向收银台，到足额时自动确认。付款中断后恢复时，可以自动补完确认。未达足额的钱可拖回钱包。
- 整理书包通过拖放装包，齐备后进入检查。点餐使用同样的物品 / 托盘 / 柜台交互。
- 保留“点选物品，再点目标”的替代操作与键盘按钮；拖拽不是唯一方式。
- 拖到无效区域、pointercancel、退出或暂停不会额外修改记录。网络不确定时使用原 Request ID 重试。
- 后端接口、数据模型、老师预览和学生正式练习边界保持不变。现有未完成会话兼容新界面。

## 设计来源

- [Apple：Designing for games](https://developer.apple.com/design/human-interface-guidelines/designing-for-games/)：按手机触控、电脑鼠标 / 键盘调整游戏输入。
- [Apple：Drag and drop](https://developer.apple.com/design/human-interface-guidelines/drag-and-drop)：物品移动的连续性、明确的落点与辅助操作。
- [Dr. Panda Supermarket](https://drpanda.com/games/DrPandaSupermarket/index.html)：在店铺世界里操作清单、货架与购物物件。
- 本地 ui-ux-pro-max 的 dragging movements 指引：保留单指点选替代方式与键盘操作，避免只能拖拽。

游戏仍可按教学逻辑记录阶段；阶段由场景动作推进，孩子界面不再呈现表单向导。服务器依据真实素材、金额和数量判断，不由前端伪造完成。

## PC 登录

移动端保留现有品牌、文案、插画与表单布局。桌面改为开放页面：顶部品牌与“机构教学 · 家庭成长”，主区域成长主题、真实场景插画及机构 / 家庭定位，旁侧登录表单。取消整块封闭的后台登录盒子；注册与登录继续使用实际 API、实际角色权限，没有虚假角色切换或假数据。

## 验证边界

真实浏览器控制再次超时。已检查用户提供的移动截图并据此改变布局约束，但不能把组件测试和 CSS 计算当作手机实机截图验收。

# 教师首页与菜单整理

根据用户的首页草图和红字归类，沿用既有 Vue / Vuetify、品牌绿色与界面规范；已读取 ui-ux-pro-max。教师首页采用卡片入口，移除原有欢迎横幅、统计卡和记录列表；教学数据仍在教学分析及原功能页面查看。

## 功能组织

- 评估中心：首页使用通用评估文案，进入后选择具体评估方法；各方法通过现有评估接口接入。
- 学业发展：学生管理、题目管理、试卷管理、作业管理、课堂练习、学生作业、学习记录、学生错题。
- 生活技能：配置与陪同生活场景训练、回看学生实际记录。
- 游戏与练习：老师课前试玩现有互动场景；仅调用课堂预览，不读取或写入学生练习记录。
- 发展技能干预：通过学生档案建立干预计划，确认目标、选择题目、布置训练、复测对比。
- 个人中心：学生档案、能力目标、教学分析和心情历史；老师自己的账户资料仍在右上角。
- 素材库：教学素材与强化物。

侧栏只展示上述业务区域及帮助等必要入口。点击区域后，再选择具体工具；首页和菜单共享名称、顺序与权限过滤。

## 权限

`RolePermission.workspaceSections` 是服务端基于当前用户角色和已有 UI/API 权限生成的响应字段，`gorm:"-"` 不写入数据库。既有模块 ID、角色授权、JWT 中间件和数据库权限规则不变。新增区域路由要求教师角色且区域内存在服务端允许的入口；未知区域、其他角色和无权限区域返回禁止访问。

## 验证

- 前端 23 个测试文件、86 项测试通过，包括八个学业入口归类、素材合并、关闭权限、教师首页不读取统计、试玩不请求学生数据。
- Go 测试与 vet 通过；真实 JWT 中间件验证当前账户角色优先于陈旧 token 角色，接口权限关闭后入口同步移除且 API 拒绝。
- 生产构建与 diff 检查通过；本地 Vite 开发服务已启动，HTTP 200。
- 使用 Codex 自带浏览器正常登录本地独立 SQLite 验收库的学生、老师、管理员账号，未注入浏览器认证状态。
- 登录页：1440×800、1024×768、768×1024，两张图片与图注均在首屏内；375×812 登录输入与按钮正常。图片改为平齐布局、完整展示，沿用原品牌。
- 老师：首页七个区域、八个学业入口、素材合并；375/768/1024/1440 无页面横向溢出。实际打开学生档案，从档案新建评估，学生自动预填；取消未创建记录。查看学生心情详情，原文与老师跟进分开。
- 学生：手机首页常用入口前移，移除重复欢迎装饰；检查自主练习、家庭作业空状态、只读评估。空题库不再允许进入无题练习。实际保存一条心情并在老师端读取。超市场景实际鼠标拖拽苹果、保存退出、重新继续，购物篮内容保留。
- 老师场景试玩实际拖拽通过；试玩不读取学生或正式练习历史，不创建正式记录。本地完成学生保存测试后仅存在一条正式场景记录。
- 管理员：手机用户管理、编辑弹窗、取消/继续编辑保留输入；iPad 权限矩阵、手机系统配置、作业审计、审计日志布局与真实数据通过，未保存权限或配置修改。
- 这轮为主要角色路径验收；空题库/无试卷的本地库不能证明完整教学任务发布与复测过程，未声称该流程全部浏览器验收通过。

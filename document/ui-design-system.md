# 一粒麦子门户界面规范

2026-10-16 起使用全新 Vue + Arco 门户。旧工作台、侧边栏、Vuetify 与 Animal Island 界面规范由本规范替代；旧代码存放于 `web/legacy/vue-2026-10-16/`。

- 信息架构：首页 / 题库 / 培训，统一顶部导航；登录后增加我的学习，管理操作按角色收在顶部管理菜单。
- 首页介绍企业定位、服务对象、支持方式，预留师资介绍；不展示课程和题库列表。
- 内容优先：题库先按年级展示目录卡片，再进入学科和主题知识点列表；培训使用受众分类、课程封面、介绍、目录与学习进度。
- 视觉：白色主体、低饱和绿色品牌、浅灰绿色分区；家长课程使用浅暖色，老师课程使用浅绿色作为内容识别。年级卡片采用品牌色系的低饱和辅助色、统一绿色链接、内嵌编号和细边框，不复刻 IXL 彩虹配色或外伸标签。字号、行距、颜色及控件样式集中在 `web/src/style.css` 和 `web/src/catalog.css`。
- 页面宽度：最大 1240px；常用 PC 三列、iPad 两列、较窄屏幕一列。无全局侧边栏；课程目录是学习页内容的一部分，小屏排列到内容上方。
- 字体：系统中文无衬线字体，不依赖远程字体请求；正文有明确行距，长文阅读保留段落与换行。
- 控件：Arco 输入、选择、弹窗、单选多选、进度及分页；统一品牌色、边界和焦点；触控操作至少 44px。
- 状态：加载/失败/重试/无内容分别处理；保存失败保留输入；未保存时取消与导航提供继续编辑/放弃修改。
- 权限：界面显示与服务端角色约束一致；家长和培训师可以浏览题库，学生作答，老师/管理员只预览；培训公开范围与指定学员在服务端分别检查。
- 进度与上传：明确区分“本机已保存/正在同步/进度已同步”；上传明确显示暂停与同文件续传方式，失败不假报成功。
- 适配：以 PC、iPad 横竖屏为主要使用场景，并兼容窄屏；支持键盘操作、输入标签、可见焦点与减少动态效果偏好。

设计参考取自用户给出的组件与网站，不使用 skill 自动推荐的儿童黏土风、紫色 AI 风或动物插画。

- 企业介绍文案以用户提供的机构介绍为依据；页脚使用独立深绿色分区，分组导航、外部文章入口和独立版权栏。公司内部链接使用路由 hash 定位，详见 `company-home-footer-2026-10-17.md`。

# 学生端布局与操作路径重构

本轮针对“上一版看起来只是改颜色”的反馈。上一版主要是 Vuetify 的 Vue 样式适配，并非直接使用 React 原组件库；不应把它描述为原库的完整移植。

## 本轮变化

- 重新读取 `animal-island-ui-style` 与 `ui-ux-pro-max`，对照原库设计规范；原库 React 组件与当前 Vue 技术栈的区别继续明确保留。
- 学生端所有常规页面取消桌面常驻侧栏，统一为顶部品牌与个人操作、底部五项常用导航、“更多”工具菜单。菜单按真实权限生成，支持焦点进入、Tab 循环、Esc 关闭与焦点恢复；教师和管理员不使用此导航。
- 首页从纵向同质卡片改成任务区、图形活动入口、学习足迹。任务区只突出第一份待完成任务，其余任务用简洁链接呈现；没有任务时明确显示实际状态。数字图形是练习入口的装饰，生活场景使用已有图片，不增加虚构统计或成就。
- 学科选择从表单块改为四个大入口，年级使用实际题目统计生成的选择项；开始按钮继续按真实题量禁用。教师保留原有选择表单。
- 新增 `IslandChoices.vue`：整张答案卡可选择，保留原答案代码，支持单选、多选、图文选项、键盘操作、选中勾选及答后锁定。使用语义化原生输入作为组件内部交互，避免不可访问的点击容器。
- 图文练习在电脑与 iPad 横屏分为左右题目区与答案区，手机纵向排列。答题时隐藏普通应用导航，只保留当前练习与退出操作。评分、重试、强化物、退出保护和提交 API 不变。
- 修正学生页面浏览器默认标题与段落外边距，避免无意撑大卡片。

## 验证与范围

- 完整前端测试 26 个文件、94 项通过；菜单焦点补充后，相关 5 个文件、13 项测试再次通过；最终生产类型检查及构建通过。
- Codex 内置浏览器检查 320×568、375×812、768×1024、1024×768、1440×900，检查浅色及深色主题。这里是浏览器视口测试，不是实体设备测试。
- 实际完成学科切换、选择答案、评分锁定、退出确认后继续、完成并保存学习记录。老师端仍显示其原有学生心情历史与跟进功能。浏览器未记录运行错误。
- 没有重新声称全部 38 个原库组件已迁移；现有表单、弹窗等仍使用 Vue/Vuetify 适配层。沿用项目规定的 MDI 图标与已有中文字体回退。

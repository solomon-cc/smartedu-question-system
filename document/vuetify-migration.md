# Vuetify 4 重构与验证记录

验证日期：2026-09-26。Vuetify 稳定版本通过 npm registry 重新核对为 4.2.2，依赖已精确锁定。

## 交付内容

- 前端入口迁移至 Vue 3.5 + Vuetify 4 + Vue Router 4，覆盖 22 个菜单页面与独立练习流程。
- 统一工作台、响应式导航、表单、空状态、错误反馈、明暗主题与键盘可访问标签。手机表格使用内部横向滚动，避免题目文本被过度挤压。
- 按权限显示菜单、保护路由，刷新后调用后端验证当前账号；令牌使用 sessionStorage。
- 题库具备服务器分页、搜索筛选、图片上传、题目编辑预览、Excel 模板和批量导入。ExcelJS 按需加载。
- 试卷、作业、练习与历史记录使用同一条真实 API 流程；作业从实际试卷加载题目，重复提交按独立学生汇总进度。
- 保留能力目标、素材、强化物及六种游戏、情绪日记、评估记录、模拟购物场景。
- 权限初始化不再覆盖管理员设置；限制学生修改教学内容及读取他人的作业、日记、评估；防止异常 JWT 导致 panic，不向客户端返回密码散列。
- 错题阶段的答案提示从后端配置派生；连续切换筛选或分页时保留最后一次刷新请求。
- 为本地真实联调增加 SQLite；生产 MySQL 配置保持可用。移除内置 JWT 密钥与空库固定管理员密码。
- 更新 README、配置示例、CI 和 Makefile。原 React 源码及开始工作时的本地修改保存在 `web/legacy/`，不参与新构建。

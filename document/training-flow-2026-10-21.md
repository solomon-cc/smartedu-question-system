# 培训流程检查与修复 · 2026-10-21

## 已修复

- 学习进度接口原先没有返回章节信息，导致前端即使已有学习记录仍显示“开始学习”。现在在权限过滤后返回章节 id、标题、类型和时长，保留原有课程字段；不返回正文或附件标识。
- 学习页处理课程 ID 与章节 URL 变化，隔离过期请求，防止切换后显示旧课程。增加 pagehide 播放位置保存，并清理媒体加载状态。
- 管理课程列表与学员名单独立加载；学员名单失败可以单独重试。指定范围要求选择学员，切回公开范围提交时清除旧学员 ID。逐章校验标题、正文或文件，保存期间锁定编辑。
- 章节重排使用稳定标识，避免文件上传组件与章节错位。
- 替换附件失败／暂停时保留原附件，并明确新文件尚未替换；不会把新文件名和旧附件成功状态混在一起。增加文件格式、大小和名称校验。
- 上传处理登录失效、非 JSON 错误、错误偏移、无进度响应及连接超时；暂停后忽略初始化／合并迟到的结果，保留服务器已接收分片。
- 课程和章节表单补齐实际输入控件的可访问名称，维持原有 Arco 组件与绿色主题。

没有新增数据库结构或扩大账号权限。线上发布同时更新后端进度接口与前端，保留上一版本的静态资源，兼容已打开的旧页面。

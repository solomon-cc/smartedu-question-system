# 官网公开介绍与平台登录入口

本次按用户补充要求调整此前的站点分离方案：官网不仅保留公司首页，还提供题库、评估、培训三个公开介绍入口。

## 访问流程

- www 首页保持现有机构、业务、师资介绍。
- www 顶部导航为：首页、题库、评估、培训。
- www 题库页展示介绍与现有题库目录，不展示作答界面。选择目录或开始练习时，前往 go 登录页，保留年级与学科目标。
- www 评估页展示方法介绍，操作入口前往 go 登录页，登录后进入评估中心。
- www 培训页直接读取正式系统已发布且公开的课程数据，显示标题、简介、讲师、培训分类；支持筛选与搜索，保持在 www。点击“登录学习”才跳到 go 登录页，并携带课程 ID。
- go 根地址对访客显示登录页。来自官网的链接统一为 `/#/login?from=website&redirect=...`。已有会话也先显示此入口，可选择“继续进入”或重新登录，不清除会话。
- 指定课程、未发布课程、学生档案、评估记录、正式施测材料和管理功能不在官网公开。

## 技术边界

官网使用独立公开路由与无认证数据客户端，不读取或发送业务会话；仅 GET `/api/portal/catalog`、`/api/portal/courses` 两个只读白名单接口可从 www 访问。Nginx 去掉转发 Cookie / Authorization，禁止写请求，其余业务 API 仍不可从 www 访问。数据来自与 go 相同的后端，不复制、不伪造课程。管理员发布公开课程后，官网重新加载会自动展示。

本次不改动后端二进制、数据库结构、账号或权限。两个站点仍独立构建，发布通过新版本目录和 Nginx 热重载完成。

- 本地验证登录后进入评估目标；已有会话再次打开官网入口仍显示登录页，“继续进入”能返回目标。

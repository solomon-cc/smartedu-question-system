# 做题页面 UI 改进 · 2026-10-21

沿用现有 Vue、Arco 与机构绿色设计规范，按 ui-ux-pro-max 的可读性、触控、语义控件和响应式要求调整。

## 改动

- 顶部合并返回入口、练习范围和小尺寸完成进度。作答后即更新进度，不再停留在 0%。
- 题干、题型和选项集中在一张答题卡。移除重复的圆点与字母两套视觉标记，保留原生单选、多选输入。
- 放大选项文字和点击区域；长选项改为单列，图片按比例显示，窄屏自然换行。
- 提交后锁定操作但保留深色文字；以文字和图标同时标出“你的选择”“正确答案”，不单靠颜色表达。
- 讲解与下一步按钮合并在底部。奖励放在其后，不再把下一题按钮推到奖励下方；去掉重复保存说明和鼓励套话。
- 填空题显示明确标签，回车提交后保留可读答案；结束页简化，返回时保留原题库筛选或评估入口。
- 为 Arco 内部原生 radio 指定同一组名，支持方向键切换；进入下一题后把焦点移到题干。
- API、服务端评分、重试请求标识、强化物规则及角色权限不变。

## 验证

- 前端 18 个测试文件、63 项测试通过。
- 增加选错标记、多选遗漏正确项、下一题状态/进度与焦点恢复的回归测试。
- 类型检查、平台构建、官网构建、Prettier 与 git diff --check 通过。
- 浏览器：学生单选正确/错误、重练；老师图片多选预览、长选项、填空回车提交。
- 尺寸：桌面 1280×720、iPad 768×1024 / 1024×768、窄屏 375×812；检查到的页面无横向溢出。
- 本地题型样例仅写入本地 SQLite，不上传生产数据库。
- 截图为本地浏览器验收；线上使用 HTTPS 文件哈希、接口权限及服务状态检查，不替代生产账号逐页视觉验收。

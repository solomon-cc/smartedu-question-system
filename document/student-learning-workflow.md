# 学生教学跟进流程

入口：教师 / 管理员的「学生管理 → 成长档案」。界面沿用项目绿色主题、Vuetify 组件与 ui-ux-pro-max 的信息层级、反馈、触控、响应式规范。

## 实际操作

1. 在学生档案新建或继续 PEAK D / G 评估。完成 64 项并确认完成后，该评估作为只读基线。
2. 在「评估发现」选择基线及需要跟进的项目。默认显示未通过项目，也可包含正确反应项目；保留原始反应和备注。
3. 老师选择已有教学目标，填写学生本次训练目标，点击「确认并保存目标」。系统保存项目关联、目标名称、目标要求和确认人员 / 时间，不会自动推断教学目标。
4. 选择关联该目标的训练题，可查看题干 / 选项图片。没有训练题时可到题库补充；新增题目预填目标，保留返回当前学生档案的入口。
5. 填写任务名称、开始日期与截止日期，布置给当前学生。服务端事务创建试卷快照、作业和计划关联；重试不会重复布置。学生从原有「我的作业」完成，提交后在档案回看。截止日当天包含在任务有效日期内。
6. 老师根据训练情况创建同版本、同模块的独立复测。复测仍按原有完整流程施测，不覆盖基线。对比展示目标关联项目的前后反应 / 备注，未评保留为空，不按 0 计算。复测完成后可从新的发现确认下一轮目标。

## 数据与权限

新增 `student_learning_plans`，由 GORM 做增量迁移。现有评估、题目、试卷、作业与训练历史继续使用现有表。正式评估项目与训练题库独立；评估身份包含 methodId、版本和模块；基线、目标关联、复测与比较通过方法接口调用。当前正式注册 PEAK，后续方法实现自己的定义、评分与对比规则。见 [评估方法接口](assessment-method-interface.md)。

新增接口均位于 `/api/students/:id/learning-plans`：GET 查看，POST 确认目标；`/:planId/assign` 布置；`/:planId/reassessment` 创建复测；`/:planId/comparison` 查看对比。

学生不能修改或读取教师目标计划；教师操作本人确认的计划，管理员可操作全部。查看 / 确认 / 复测额外要求教学目标与评估权限，布置额外要求题库、试卷与作业权限，不能借学生档案入口绕过模块权限。

确认后的目标保留快照。方向改变时确认新目标，避免改写此前训练依据。对比为原始反应记录，不提供标准分、诊断、稳定掌握或训练因果结论。

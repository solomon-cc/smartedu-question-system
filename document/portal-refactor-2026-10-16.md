# 一粒麦子门户重构与本地验收

更新：2026-10-17。门户已发布到生产；后续首页文案与页脚更新见独立发布记录。

## 页面与视觉

- 首页改为企业介绍：企业定位、服务孩子/家庭/老师、支持方式、预留师资。现有文案依据用户提供的机构介绍截图整理，涵盖早期干预、融合支持、家庭指导与评估追踪；不虚构企业年限、认证、案例、评价或教师档案。
- 师资区明确“资料整理中”，支持首页按钮定位、键盘焦点转移。后续可填真实老师照片、姓名、专业背景和教学方向；本轮没有新增师资管理 API。
- 题库借鉴 IXL 的年级到学科的信息组织，视觉重新设计为低饱和品牌辅助色、细边框、内嵌编号、统一绿色链接；去掉原有彩色整框和外伸编号。
- 培训删除家长/老师两张重复入口卡片，使用分类标签与搜索。课程标题只展示一次。
- Vue 3 + Arco，统一顶部导航。管理功能收于登录后的管理菜单。
- ui-ux-pro-max 用于层级、可读性、触控、焦点与响应式检查；不采用与用户要求不符的自动风格建议。

## 参考的具体用途与边界

- [Arco Spin](https://arco.design/vue/component/spin)：加载反馈；实际使用 Arco 输入、弹窗、选择、进度等组件。
- [Mantine UI](https://ui.mantine.dev/)：内容卡片、标题与操作的清晰分层；没有混装 React 组件。
- [TDesign Starter](https://tdesign.tencent.com/starter/)：表单与管理内容的组织参考。
- [Land-book](https://land-book.com/) 与 [One Page Love](https://onepagelove.com/)：企业首页的内容顺序、留白与品牌表达参考。
- 已查看用户提供截图及此前可访问的组件/图库页面。Pinterest 部分页面需要登录或加载超时；本次不能声称完整查看了所有 Pinterest、花瓣和 Dribbble 案例。

## 权限与流程

| 角色 | 作答 | 培训 | 管理 |
| --- | --- | --- | --- |
| 游客 | 浏览目录，登录后进入 | 浏览公开课程介绍 | 无 |
| 学生 | 服务端判分，写自己的练习记录 | 已授权课程和个人进度 | 无 |
| 家长 | 浏览目录 | 公开或指定给自己的课程 | 无 |
| 老师 | 预览，不写学生记录 | 已授权课程 | 题库 |
| 培训师 | 浏览目录 | 已授权课程 | 自己的课程与指定学员 |
| 管理员 | 预览，不写学生记录 | 所有管理范围内容 | 题库、课程、用户与多个管理员 |

课程支持文字、文档、视频和排序；公开/指定用户、草稿/发布在服务端检查。学习位置本地暂存并同步至服务端。上传使用 4 MiB 分片、校验与服务端确认偏移；暂停或中断后选择相同文件继续。媒体签名访问持续检查用户和课程权限，支持 Range。没有视频转码服务；视频须由浏览器支持对应编码，Office 文档通常下载后打开。
